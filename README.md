# Xealeus State-Machine Engine (xealeus-engine)

A deterministic, open-source software harness and state-machine compiler for the Voynich Manuscript.

---

## Overview

The Xealeus State-Machine Engine is a fully reproducible Python test suite and state-machine compiler designed to reverse-engineer the text of the 15th-century Voynich Manuscript.

Rather than treating Voynichese as an encrypted natural human language requiring semantic translation, this framework proves that the manuscript was generated by a procedural state-machine generative grammar operating on rigid positional slot rules (Prefix -> Core -> Suffix), line-level data packet envelopes, horizontal domino chaining, and 2D spatial layout constraints.

This repository contains a master test runner (run_all_tests.py), five core modular validation scripts, and a creative data sonification tool:
1. run_all_tests.py: Master Test Harness that executes all five verification suites sequentially in a single pass.
2. test_deep_structure.py: Morphological parser, line-envelope positional profiling, and information-theoretic slot coupling metrics (Normalized Mutual Information).
3. test_currier_ab.py: Cross-dialect Middle Core stem transfer analysis between Currier A and Currier B.
4. test_voynich_compiler.py: A memoryless 3-stage Markov state-machine compiler that trains on held-out manuscript data to synthetically generate legal Voynich line packets (Compiler V1).
5. test_compiler_v2.py: Advanced compiler incorporating inter-word domino chaining (W[t] -> W[t+1]) and Core-to-Core state memory (Core[t] -> Core[t+1] ~ 1.20 bits MI), closing the line-level compression delta (0.313 bits/word in A / 0.460 in B) and recovering 87.5% - 89.9% of real vocabulary (Compiler V2).
6. test_diagram_geometry.py: 2D physical layout and spatial geometry analyzer, classifying Takahashi locators into PARAGRAPH, RING, SPOKE, and LABEL units. Demonstrates recursive looping in circular rings and 16.03% vertical same-core persistence down adjacent paragraph lines.
7. voynich_lute_tactus.py: Audio Sonification Easter Egg that translates the state machine's positional slots and domino chaining into a 15th-century medieval stereo lute duet.

## Required Corpus Dataset: LSI_ivtff_0d.txt

To execute the verification suite, you need the cleaned Interlinear Voynich Transliteration File Format (IVTFF) corpus compiled by Jorge Stolfi and Rene Zandbergen based on Takeshi Takahashi's transcription (LSI_ivtff_0d.txt).

Place LSI_ivtff_0d.txt into the root directory of this repository before running the scripts.

## Key Empirical Findings

1. First-Order Markov Chain (Prefix -> Core -> Suffix):
  - Prefix <-> Core Coupling: ~30-40% NMI
  - Core <-> Suffix Coupling: ~30-40% NMI
  - Prefix <-> Suffix Direct Coupling: ~5-7% NMI (Near-Zero Direct Memory)

2. Line-Level Data Envelopes:
  - Line-Initial Gallows Headers: Concentrate at START positions (up to 68.5% in Zodiac).
  - Line Termination Stop Bit (-am): Spikes to become the #1 line-ending suffix across Currier B (15.6%), Stars (19.2%), and Cosmological (21.5%).

3. Unified Stem Table Across Currier A & B:
  - Over 90% of token mass in Currier B utilizes Middle Cores present in Currier A.

4. Inter-Word Domino Chaining (Compiler V2):
  - Core[t] -> Core[t+1] delivers ~1.20 bits of Mutual Information.
  - Reduces zlib order_delta_bits to 0.313 bits/word (Currier A) and 0.460 bits/word (Currier B).
  - Reconstructs 87.5% - 89.9% of real attested vocabulary on unseen test lines.

5. 2D Spatial & Diagram Layout Modulation:
  - Circular RING and LABEL units trigger recursive reduplication (e.g. oteotey, okeokedr).
  - Paragraph blocks exhibit 16.03% vertical same-core persistence down adjacent lines.

## Easter Egg: Audio Sonification & Lute Tactus (voynich_lute_tactus.py)

In addition to the formal statistical verification suite, the repository includes a creative audio sonification script, voynich_lute_tactus.py.

Note: This script is not a claim that the Voynich Manuscript is a secret musical score or sheet music. Rather, it is a creative data sonification experiment designed to demonstrate how the 3-slot positional state machine (P -> C -> S) and inter-word domino chaining (Core[t] -> Core[t+1]) translate directly into authentic 15th-century modal musical structures.

### Audio Mapping Mechanics
- Karplus-Strong Physical String Modeling: Simulates a 15th-century double-strung gut lute plucked with a quill, incorporating wooden soundboard resonance and decay.
- 7-Note D Dorian Core Scale: The 7 most common middle core stems (_, e, ch, k, a, o, t) map deterministically onto the degrees of the D Dorian scale. Because adjacent words carry 1.20 bits of Core-to-Core mutual information, the resulting melody forms smooth, evolving modal ostinatos rather than random pitch jumps.
- Currier A vs. Currier B Lute Duet: Currier A is assigned to the Discant Lute (Octave 4, right channel), while Currier B acts as the Tenor Lute (Octave 3, left channel).
- Tempus Perfectum (3/4 Tactus Grid): Word measures execute on a rigid 15th-century triple-meter pulse (0.84s per measure).
- Gallows Drones & Landini Cadences: Line-initial gallows headers (p-, t-, k-, f-) strike deep open-course bass drones, while -am line-ending stop bits trigger a 15th-century Landini cadence.
